## 概要

脱炭素は必要である。

CO₂排出を減らし、再生可能エネルギーへ移行し、省エネルギーを進め、産業構造を変えることは、気候対策の重要な一部である。

しかし、脱炭素だけでは、地球温暖化と気候変動を解決するには不十分である。

より深い問題は、人間文明がCO₂を出しすぎていることだけではない。

人間文明は同時に、地球が炭素を吸収し、固定し、貯蔵し、再循環する自然能力そのものを傷つけてきた。

つまり、大気中CO₂が増えたのは、人間が排出したからだけではない。

地球の炭素固定システムと炭素吸収システムが弱体化してきたからでもある。

従来の気候モデルは、次のように表される。

```text
人間活動
→ CO₂排出の増加
→ 地球温暖化
→ 気候変動
```

このモデルは間違いではない。

しかし、不完全である。

より深い因果モデルは、次である。

```text
人間活動
→ 土壌・森林・海洋・湿地・微生物循環の破壊
→ 炭素固定システムと炭素吸収システムの弱体化
→ CO₂が吸収・固定・貯蔵・再循環されにくくなる
→ 大気中CO₂が蓄積する
→ 地球温暖化が加速する
→ 気候変動が激化する
```

したがって、次の段階の気候対策は、以下へ進まなければならない。

```text
脱炭素だけから
脱炭素 + 炭素固定源回復へ。
```

脱炭素は必要である。

CO₂排出削減は、気候方程式の片側にすぎない。

もう一方には、炭素吸収源、炭素固定システム、土壌炭素、微生物循環、森林、湿地、海洋、自然水循環の回復がある。

```text
地球は、炭素を処理する能力を失いつつある。
```

```text
CO₂排出を減らす。
```

から、

```text
CO₂排出を減らす
```

へ。

## 1. 脱炭素とは何か

脱炭素とは、一般に、人間活動から発生する温室効果ガス、とくにCO₂排出を削減することを意味する。

それには以下が含まれる。

```text
再生可能エネルギー
省エネルギー
電化
電気自動車
化石燃料使用の削減
産業構造の転換
カーボンプライシング
カーボンクレジット
炭素回収
ネットゼロ政策
カーボンニュートラル
```

これらの対策は重要である。

それらは、大気中へ入るCO₂の量を減らす。

しかし、脱炭素は主に問題の「排出側」に焦点を当てている。

脱炭素だけでは、以下は自動的には起こらない。

```text
損傷した土壌は回復しない。
微生物生態系は再構築されない。
複雑な森林は再生されない。
湿地は回復しない。
海洋生態系は修復されない。
壊れた自然循環は再起動しない。
```

これが、脱炭素の中心的限界である。

## 2. なぜ脱炭素は必要なのか

CO₂は温室効果ガスである。

大気中CO₂が増加すると、地球の放射収支に影響し、地球温暖化に寄与する。

したがって、CO₂排出削減は必要である。

排出削減がなければ、大気中CO₂は増え続ける。

つまり、脱炭素を無視することはできない。

しかし、重要なのは次である。

```text
必要であることは、十分であることを意味しない。
```

脱炭素は必要である。

しかし、脱炭素だけでは壊れた炭素循環を修復できない。

## 3. 気候方程式の欠けた半分

多くの公共的な気候議論は、排出に焦点を当てる。

一般的な問いは、次である。

```text
どうCO₂排出を減らすか。
```

これは重要である。

しかし、それは方程式の半分にすぎない。

より深い問いは、次である。

```text
地球がCO₂を吸収し、固定し、貯蔵し、再循環する能力をどう回復するか。
```

大気中CO₂は、排出量と吸収源の両方によって左右される。

単純化した技術モデルは以下である。

```text
大気中CO₂増加 =
人間由来CO₂排出
- 陸上炭素吸収
- 海洋炭素吸収
- 長期的な生物・地質的炭素固定
+ 生態系劣化による炭素放出
```

つまり、大気中CO₂は以下の場合に増加する。

```text
人間の排出が増える
炭素吸収源が弱まる
貯蔵炭素が放出される
土壌炭素が減少する
森林が劣化する
湿地が消える
海洋生態系が弱まる
微生物による炭素処理が低下する
```

主流の脱炭素論は、第一の要因を強調する。

本稿は、方程式全体を強調する。

## 4. CO₂は原因であり、症状でもある

CO₂は温暖化の直接的な物理要因である。

これは否定すべきではない。

しかし、CO₂蓄積は、損傷した惑星炭素循環の症状でもある。

CO₂は、人間が排出したから増えた。

しかし、CO₂が蓄積し続けるのは、地球の自然な吸収・固定能力が弱体化したからでもある。

したがって、CO₂は以下である。

```text
大気レベルでは温暖化の直接原因
+
惑星システムレベルでは炭素循環不全の症状
```

CO₂を排出問題だけとして扱うなら、解決策は狭くなる。

```text
排出を減らす。
```

しかし、CO₂蓄積を炭素循環不全として理解すれば、解決策は広がる。

```text
排出を減らす。
炭素吸収源を回復する。
土壌炭素を再構築する。
微生物循環を回復する。
森林を再生する。
湿地を回復する。
海洋生態系を支える。
自然水循環を修復する。
```

これが、多くの脱炭素議論に欠けている方向である。

## 5. カーボンニュートラルは本来、吸収を含んでいる

カーボンニュートラルは、一般に温室効果ガス排出量を除去量や吸収量と釣り合わせることとして説明される。

原理的には、カーボンニュートラルは排出削減だけを意味しない。

それは、炭素吸収を維持し、強化することも必要とする。

しかし、公共的議論、政策、企業広報では、焦点が以下へ偏りやすい。

```text
再生可能エネルギー
電気自動車
エネルギー転換
排出会計
カーボンクレジット
産業排出削減目標
```

これらは重要である。

しかし、カーボンニュートラルの生態学的基盤を十分に扱っていない。

真のカーボンニュートラルには、以下が必要である。

```text
排出削減
+
炭素吸収源保護
+
炭素固定源回復
+
生態系再生
```

自然炭素吸収源の回復がなければ、カーボンニュートラルは惑星回復戦略ではなく、会計上の枠組みにとどまる危険がある。

## 7. 微生物の見えない役割

微生物は、脱炭素の議論からしばしば抜け落ちている。

しかし、微生物は炭素固定と土壌炭素形成の中心にいる。

土壌微生物は以下を担う。

```text
有機物の分解
栄養の変換
植物根の支援
土壌構造の形成
腐植形成への関与
土壌有機炭素への寄与
保水力への影響
炭素放出と炭素貯蔵の制御
```

微生物は単なる分解者ではない。

炭素処理者である。

炭素がすぐに大気へ戻るのか、土壌中で安定化するのかを左右している。

微生物生態系が衰退すれば、炭素循環は弱まる。

その結果は、土壌肥沃度の低下だけではない。

惑星規模の炭素固定システムの弱体化である。

## 8. なぜ脱炭素だけでは不十分なのか

脱炭素だけでは不十分である理由は、大きく五つある。

### 8.1 劣化した土壌は自動的に回復しない

CO₂排出を減らしても、土壌有機炭素はすぐに回復しない。

以下は自動的には再構築されない。

```text
微生物ネットワーク
腐植
根圏生態系
土壌構造
保水力
栄養循環
炭素貯蔵能力
```

土壌再生には、能動的な回復が必要である。

### 8.2 木を植えるだけでは森林は回復しない

森林は、木の集合体ではない。

本物の森林は、次を含む複雑な生態系である。

```text
樹木
下層植生
菌類
土壌微生物
昆虫
動物
水循環
土壌炭素
生物多様性
```

単一樹種の植林は、成熟した多様な森林生態系を完全には代替できない。

植えた木の本数だけを数える森林再生では、本当の炭素固定能力を回復できない可能性がある。

### 8.3 海洋炭素吸収源は見えにくい

海洋は主要な炭素吸収源である。

海洋は、人為的CO₂と熱の大きな部分を吸収している。

しかし、海洋温暖化、酸性化、汚染、栄養循環の攪乱、生態系衰退は、海洋の炭素吸収能力を弱める。

海洋炭素吸収源が弱まれば、より多くのCO₂が大気中に残る。

したがって、脱炭素は海洋再生と接続されなければならない。

### 8.4 有機物が自然循環から取り除かれている

落ち葉、枝、食品廃棄物、作物残渣、その他の有機物は、本来、土壌と微生物循環へ戻るべきである。

しかし現代社会では、有機物が焼却され、廃棄され、地域生態系から取り除かれることが多い。

これは有機炭素循環を断ち切る。

有機物はゴミではない。

土壌炭素、微生物生命、腐植形成の原料である。

脱炭素には、有機物循環の回復も含まれるべきである。

### 8.5 気候変動そのものが炭素吸収源を弱める

温暖化は炭素吸収源を傷つける。

それは以下を増やす。

```text
干ばつ
山火事
森林ストレス
土壌劣化
海洋ストレス
生態系崩壊
農業不安定化
```

これらは地球の炭素吸収・貯蔵能力を弱める。

この結果、フィードバックループが生じる。

```text
CO₂蓄積
→ 地球温暖化
→ 干ばつ・火災・海洋ストレス・土壌劣化
→ 炭素吸収源の弱体化
→ より多くのCO₂が大気中に残る
→ さらなる温暖化
```

このフィードバックは、排出削減だけでは解決できない。

炭素吸収源回復が必要である。

## 9. 壊れた貯水池の比喩

脱炭素は、壊れた貯水池へ流れ込む水量を減らすことに似ている。

貯水池が健全なら、流入を減らすだけで十分かもしれない。

しかし、貯水池そのものが割れ、漏れ、構造的に損傷しているなら、流入を減らすだけでは不十分である。

貯水池自体を修理しなければならない。

気候システムでは、以下に対応する。

```text
流入 = 人間由来CO₂排出
貯水池 = 土壌・森林・海洋・湿地・炭素吸収源
漏れ = 劣化した生態系から放出される炭素
修理 = 炭素固定システムの回復
```

したがって、気候対策には以下の両方が必要である。

```text
流入を減らす
+
貯水池を修理する
```

## 12. 結論

脱炭素は必要である。

しかし、脱炭素だけでは地球温暖化を止めるには不十分である。

CO₂排出は温暖化の直接要因である。  
しかし、大気中CO₂の継続的な蓄積は、地球の炭素固定システムが壊れている症状でもある。

地球は、炭素を過剰に出されているだけではない。

地球は、炭素を吸収し、固定し、貯蔵し、再循環する能力を失いつつある。

したがって、次の気候戦略は以下である。

```text
脱炭素
+
炭素固定源回復
+
微生物・生態循環回復
```

気候戦略の未来は、以下へ進むべきである。

```text
脱炭素だけから
惑星炭素代謝の回復へ。
```

あるいは、より簡潔に言えば、

```text
CO₂を減らすことから
地球がCO₂を処理する能力を回復することへ。
```
